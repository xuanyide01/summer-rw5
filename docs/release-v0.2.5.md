# 夏日口袋 0.2.5 · REDMI Watch 5

维护者于 **2026-10-26** 确认本版本已通过 REDMI Watch 5 实机测试。

本次发布整合 0.1.7 之后的更新：

- 原作标题背景、标题所用白羽形象及透明按键；放大 Logo 并在顶部居中，按键在左侧竖排、增大间距，去掉右下角小字。
- 按原作进度显示 ReSTART / ALKA / Pocket，独立保存通关标记。
- 菜单增加三档自动播放：逐字显示后等待，遇选项暂停，玩家选择后继续。
- 修复目录曲加载与播放生命周期，使用单音频流及主动停止重播；标题、LOAD、GALLERY 与单张 CG 鉴赏切换不断流。读档进入剧情、切后台及退出时停止。
- 无损重压缩图片并合并重复立绘；图片、字体、音频不再使用 ZIP DEFLATE，降低安装解压工作。CG 和游戏内立绘沿用已检查画质；为保持完整目录曲及包体上限，音频为 PCM 16 位 / 4 kHz 单声道，高频细节减少。
- 保留 30 个存档栏位、CG 差分分组、安全下一章以及旧存档格式。

## 下载

安装只需 `summer-rw5-v0.2.5.bin` 或内容相同的 `.rpk`，文件均为 **24,983,953 字节**，低于 25 MB。

源码与资源分别位于 `summer-rw5-v0.2.5-source.zip` 和 `summer-rw5-v0.2.5-resources.zip`，开发时解压到同一目录，使文件合并到 `summer-rw5/`。安装游戏不需要这两个 ZIP。所有附件均小于 25,000,000 字节。

## 安装与验证

使用“表盘自定义工具”等支持 REDMI Watch 5 的工具。**工具提示安装完成后，仍需等待手表端真正安装结束**再打开，不要反复重装。更新前保留旧包和存档；卸载可能清除存档。

47 项自动检查通过。官方 Vela 原生模拟器检查了跨界面音乐连续播放、CG 内整曲循环、旧第 30 栏存档加载、音乐停止及返回标题。模拟器本次使用最终编译页面更新检查，未重复完整 0.2.5 RPK 安装；维护者随后确认最终版本实测通过。实机反馈未提供固件版本和逐项清单，不能据此推定所有固件或跨应用组合均已覆盖。

音频异常时可先在 OPTIONS 关闭标题音乐、退出再重新打开；其他应用仍无声时，完整退出本游戏后重开原应用，必要时重启手表。更多说明及无响应处理见附件 `README.md` 与仓库 [0.2.5 更新说明](https://github.com/xuanyide01/summer-rw5/blob/main/docs/v0.2.5.md)。历史正式版保留供回退。
