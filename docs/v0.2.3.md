# 0.2.3：标题音乐与安装封装

本次针对 REDMI Watch 5，安装文件 `summer-rw5-v0.2.3.bin` 与同名 RPK 内容一致，均为 **24,985,697 字节**，低于 25,000,000 字节。包名不变，versionCode 为 12。请使用其中一个文件安装。

SHA256：`1525c2ffcaa83bdc37da18a18d63bfa198a724ae4b4f34ce11b528ebad2c5198`。

## 标题与目录曲

按维护者选定的 A 配色，原作透明按键使用米白字、深蓝描边和轻阴影，左侧竖排，字形对齐线为 x=42 px。背景采用原版 `OTHCG.PAK/__SYS_TM_BG01A`，叠加原版白羽完整立绘 `CHARCG.PAK/BS2_SR01121101`；不再使用港口截图或唱片封面。ReSTART、ALKA、Pocket 的通关出现条件保持不变。

参考本地《命运石之门》《命运石之门 0》《CLANNAD》的播放方式，将原来的 IMA ADPCM WAV 改为 **PCM signed 16-bit little endian**。保留原作 BGM32 的完整 237 秒，附加 2 秒静音尾段；在静音尾段内、文件结束前主动停止，等待 1.2 秒后重建播放，不启用原生 loop，不轮询播放器属性或 seek。

为同时满足完整曲目、PCM 格式、图像画质与 25 MB 上限，目录曲采用 **4 kHz 单声道**，高频细节会减少，声音会比先前版本更闷。另三款的具体采样率不同；本版本只沿用其 PCM 格式及停止重建方法，不能将它们的实机通过记录算成本版本的实机通过记录。

外部暂停或停止通知会取消后续重播；后台、剧情、CG、存档及退出均停止标题音乐。设置资源路径失败时也会清理已经申请的播放流；10 秒没有收到音频加载完成回调时停止并显示重试入口。应用和页面退出均有清理。应用不写入系统音量或静音设置，也不会在自己没有申请播放时调用停止。

接口依据：[小米 Vela 音频](https://iot.mi.com/vela/quickapp/en/features/other/audio.html)、[应用全局对象](https://iot.mi.com/vela/quickapp/zh/guide/framework/script/global-data-method.html)。

## 减少安装解压

| 项目 | 0.2.2 | 0.2.3 |
| --- | ---: | ---: |
| 安装包字节数 | 24,846,321 | 24,985,697 |
| 包内文件原始大小合计 | 34,038,472 | 34,007,788 |
| 需要 DEFLATE 解压的文件数 | 1,682 | 461 |
| 需要 DEFLATE 解压的原始字节数 | 19,782,267 | 11,511,497 |
| 最大 DEFLATE 条目的原始字节数 | 631,876 | 327,005 |

参考《命运石之门 0》《CLANNAD》的封装方式，PNG、JPEG、WAV、字体全部采用 ZIP STORE，只有为满足上限所需的文本使用 DEFLATE；保留已有逐字节验证的文本压缩缓存。需要解压的原始数据量下降约 **41.8%**。这些是包结构指标，未测量真实固件的峰值堆内存。

合并 15 份完全相同的立绘文件，节省 **652,663 字节**；仍保留 277 个逻辑立绘条目与全部原资源 ID，实际图片为 262 份。保留图片的文件字节不变，重复图片的 RGBA 像素也完全一致。字体去掉不用的竖排元数据，字形程序、横向度量、Unicode 映射及横排布局表逐字节不变。剧情、全部 CG、地图数据、旧存档键及指令位置保持不变。

PCM 体积增大抵消了大部分资源节省，因此安装包比 0.2.2 略大；本次优化主要降低安装解压工作量，没有进一步降低剧情 CG 或立绘的画质。

43 项自动检查全部通过，包括 1,000 次模拟循环、解码报错、资源路径设置失败、加载超时、外部停止、应用销毁、30 栏旧存档格式、自动阅读和通关按键。ZIP CRC 和全部可核对资源/编译文件的一致性检查通过。

最终包已在独立官方 `vela-watch-5.0` 模拟器安装、启动；已读回清单、代码、目录曲、字体与标题资源，确认与最终包对应文件一致。模拟器读取新 PCM 并向 8 kHz 输出端重采样，播放进度正常。连续完成两次完整曲目停止和重播，第三轮成功开始；旧第 30 栏存档恢复、菜单自动阅读及 CG 差分切换通过。正常退出后，另一款音频探针应用成功加载、播放并推进到 14.592 秒，证明此测试流程下音频焦点已交还。具体结果见随附 JSON 报告。

覆盖安装曾返回 `-19`，伴随安装器写文件失败日志，确切原因未定；随后备份虚拟存档并全新安装，最终已安装资源和启动检查通过。跨应用并行启动探针时发生过原生数据访问异常，该次跨应用检查不算通过；详细后续结果见 `native-audio-release-v023.json`。**本版本仍需新的 REDMI Watch 5 实机反馈，不能保证所有固件或其他应用的音频兼容性。**

## 安装及异常处理

1. 更新前保留旧安装包和存档；优先使用安装工具的覆盖更新，卸载可能清除进度。工具提示完成后仍需等待手表端安装结束，再打开应用，避免反复安装。
2. 标题无声时，先在 OPTIONS 关闭标题音乐，退出后重新进入，再尝试开启或点击重试。检查手表系统媒体音量。若出现其他应用无声，先完整退出本游戏，再重新打开原应用；仍异常则通过手表系统菜单重启。记录手表固件和触发步骤，暂时保持标题音乐关闭。
3. 安装报错时先退出游戏、确认可用空间并等待安装工具结束；不要连续重试或直接卸载有存档的旧版。模拟器的重装操作不代表真实设备必须重装。
4. 屏幕完全无响应时，小米 REDMI Watch 5 官方 FAQ 给出的操作是：**长按电源键约 18 秒，直到 REDMI 标志出现再松开**，强制关机重启。此操作依据 [REDMI Watch 5 官方 FAQ](https://www.mi.com/pk/support/faq/details/KA-521474/)，不是恢复出厂设置。

## 源码与资源归档

为了让每个归档文件也低于 25 MB，源码和转换后资源分别提供：`summer-rw5-v0.2.3-source.zip` 与 `summer-rw5-v0.2.3-resources.zip`。两份解压到同一目录，会共同组成 `summer-rw5` 项目；安装游戏只需 BIN 或 RPK，无须这两个归档。

`tools/optimize-resources-v023.py` 可在重新转换后合并重复立绘并精简竖排字体元数据；`tools/prepare-title-audio.py` 重新生成 PCM；`tools/build-title-v023.py` 从原版 PAK 重建标题背景和立绘组合。转换后的 A 按键 PNG 随资源提供。原作素材和第三方字体不属于自编代码的 MIT 授权范围。
